1. Install Node.js (v16+ or v18+ recommended).

2. Create project folder and enter it:
    mkdir my-express-app
    cd my-express-app

3. Initialize npm:
    npm init -y

4. Install Express:
    npm install express

5. Create a basic server file (server.js):
    const express = require('express')
    const app = express()
    const port = process.env.PORT || 3000

    app.get('/', (req, res) => {
      res.send('Hello World')
    })

    app.listen(port, () => {
      console.log(`Server listening on http://localhost:${port}`)
    })

6. Add a start script to package.json:
    "scripts": {
      "start": "node index.js",
      "dev": "nodemon index.js"
    }

7. Run the app:
    npm start
    (or for auto-reload during development)
    npm install --save-dev nodemon (or -D to replace --save-dev)
    npm run dev

8. Add common middleware and structure:
    - app.use(express.json())            // parse JSON bodies
    - app.use(express.urlencoded({extended:true})) // parse form bodies
    - Organize routes into ./routes and use app.use('/api', require('./routes/...'))

9. Add environment variable support:
    npm install dotenv
    Create a .env file and load with require('dotenv').config()

10. Error handling and 404:
     - Add a catch-all 404 handler and a centralized error-handling middleware.

11. Testing and linting (optional but recommended):
     - npm install --save-dev jest supertest
     - npm install --save-dev eslint prettier

12. Version control and ignore:
     git init
     Create .gitignore with node_modules, .env, .env.local

13. Deployment notes:
    - Use process.env.PORT, set NODE_ENV=production
    - For small apps: deploy to Heroku / Vercel / Railway / Render
    - For servers: use PM2 or a systemd service for production

14. Set up EJS templating:
    npm install ejs
    Set view engine in index.js:
      app.set('view engine', 'ejs')
      app.set('views', './views')
    Create ./views folder for .ejs template files

15. Create routes structure:
    - Create ./routes folder
    - Example routes/notes.js:
      const express = require('express')
      const router = express.Router()
      router.get('/', (req, res) => {
        res.render('notes/index', { title: 'Notes' })
      })
      router.get('/:id', (req, res) => {
        res.render('notes/show', { id: req.params.id })
      })
      module.exports = router
    - In index.js: app.use('/notes', require('./routes/notes'))

16. Create EJS views:
    - Create ./views/notes/ folder
    - Create views/notes/index.ejs:
      <h1><%= title %></h1>
      <ul><!-- list notes --></ul>
    - Create views/notes/show.ejs:
      <h1>Note <%= id %></h1>

17. Use partials and layouts:
    - Create views/layout.ejs (header, footer, nav)
    - Use <%- include('./partials/header') %> in templates
    - Wrap content with <%- include('layout') %> pattern

18. Useful commands summary:
    - npm install <pkg>           // install dependency
    - npm install -D <pkg>       // install dev dependency
    - npm start                  // run production start
    - npm run dev                // run development server (nodemon)
